TIGERSOFT Handover V13
Baseline: V12

ปรับเฉพาะกติกาการจัดรูป/ตารางใน PDF:

- 0 รูป: แสดงรายละเอียดอุปกรณ์ในหน้า Location
- 1 รูป: รูปใหญ่ + รายการอุปกรณ์หน้าเดียวกัน
- 2 รูป: 2 รูป + รายการอุปกรณ์หน้าเดียวกัน
- 3 รูป: 2 รูปบน + 1 รูปล่างกึ่งกลาง + รายการอุปกรณ์หน้าเดียวกัน
- 4 รูป: 2 x 2 + รายการอุปกรณ์หน้าเดียวกัน
- 5 รูป: จัดรูป 2+2+1 และรายการอุปกรณ์หน้าถัดไป
- 6 รูป: จัดรูป 2 x 3 และรายการอุปกรณ์หน้าถัดไป
- มากกว่า 6 รูป: แบ่งสูงสุด 6 รูป/หน้า และรายการอุปกรณ์อยู่หลังหน้ารูปทั้งหมด

รูปใช้ object-fit: contain เพื่อรักษาสัดส่วนภาพแนวตั้งและไม่ Crop

Default Equipment, Serial Scan, Font, UX และหน้า PDF อื่นคงเดิม
